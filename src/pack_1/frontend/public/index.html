BANK-GRADE SECURITY

Engineered With Security in Mind

Learn how Rajarata Digital Bank protects customer assets and personal identity.

PBKDF2 Password Hashing

Passwords are never stored in plain text. PBKDF2-HMAC-SHA256 with 120,000 iterations and cryptographic salts safeguards credentials.

Atomic ACID Transactions

Money transfers execute as atomic SQLite transactions. If an error occurs on either account, the entire operation rolls back automatically.

Role-Based Authorization

Customer sessions are isolated with cryptographic bearer tokens. Administrative commands require verified admin privileges.
